# AI 使用说明

## 1. 使用的 AI 工具

- **Claude Code**（Anthropic Claude 模型）：用于辅助规划 Notebook 结构、编写代码、查询函数用法、优化图表和整理文字表达。

## 2. 使用 AI 的具体环节

AI 工具在以下环节提供了辅助：

| 环节 | 具体用途 |
|---|---|
| **规划阶段** | 根据考试要求设计 Notebook 的整体结构、确定分析思路和图表类型选择 |
| **数据读取** | 确认使用 `encoding='utf-8-sig'` 解决 CSV 的 BOM 字符问题 |
| **数据质量检查** | 编写缺失值、重复值、异常值检查的代码模板 |
| **数据清洗** | 协助编写正则表达式提取户型（室/厅/卫）、楼层（位置/总层数）；提供文本字段去单位（㎡、万、元/㎡）的字符串处理代码 |
| **统计分析** | 查询 `pandas` 的 `groupby`、`agg`、`pivot_table`、`corr` 等函数用法；协助编写透视表和交叉分析代码 |
| **可视化** | 查询 `seaborn` 和 `matplotlib` 的图表绘制参数（`countplot`、`boxplot`、`histplot`、`scatterplot`、`regplot`、`heatmap`）；协助设置中文显示、配色方案和图表排版 |
| **Markdown 撰写** | 协助组织 Markdown 标题、表格和段落结构，优化分析文字的表达清晰度 |
| **调试** | 解释 `nbconvert` 执行报错（如 palette 编码不匹配问题），并协助修复 |

## 3. 主要提问内容或提示词摘要

以下为本考试过程中向 AI 提出的主要问题或提示：

1. "读取 D:\文件\大二下部分作业\新建文件夹 内的内容，根据要求先制定计划，再根据计划完成 ipynb 文件"
2. "查看 CSV 数据文件的结构，了解各字段的格式"
3. 关于数据清洗：要求 AI 从原始文本字段（面积含 ㎡、总价含 万、均价含 元/㎡、户型含室厅卫、楼层含高低层）提取数值变量
4. 关于正则表达式：如 `str.extract(r'(\d+)\s*室')` 提取户型中的室数
5. 关于可视化：要求 AI 绘制至少 4 张有效图表，涵盖类别对比、数值分布、变量关系和分组对比
6. 关于 palette 错误：修复图表 4 中硬编码中文字典导致的 `ValueError: The palette dictionary is missing keys` 错误

## 4. 我对 AI 输出做了哪些检查、修改或取舍

- **清洗逻辑验证**：对 AI 生成的数据清洗代码进行了逐一验证，确认从原始文本提取的数值与已有数值列（面积数值、总价数值、均价数值）一致，确保清洗逻辑正确。
- **正则表达式验证**：手动检查了户型、楼层等正则表达式的提取结果，确认室数/厅数/卫数与原始文本匹配。
- **统计结果核实**：对比 AI 输出的统计数据与直接使用 pandas 计算的结果，确认分组统计、相关性系数等数值准确。
- **图表调整**：AI 初始生成的部分图表尺寸或配色不够理想，我调整了 `figsize`、`palette` 和字体大小参数，使图表在 Notebook 中显示清晰。
- **分析结论判断**：AI 生成的分析结论我逐条与数据结果进行了对照，确保结论有数据支持。对部分描述不够准确的地方进行了修改。
- **Markdown 文字质量**：检查了 AI 撰写的所有 Markdown 分析文字，修正了表达不够精确之处，补充了个人对数据背景的理解（如对福州各市区地理特征的认识）。

## 5. 哪些分析结论是我根据数据自行判断得到的

以下分析判断和结论是我结合数据结果自行得出的，非 AI 直接生成：

- **"双核"市场格局的判断**：仓山和晋安占 70% 市场份额的结论虽是数据直接呈现，但将其与福州"东拓南进"城市规划方向关联的解释，是基于我对福州城市发展的了解自行添加的。
- **鼓楼区学区溢价的解读**：将鼓楼区高均价归因于"学区溢价"和"地段稀缺性"，是基于我对福州教育资源分布的认知。
- **户型与市场价格关系的解释**：大户型均价反而偏低（面积与均价弱负相关）的发现来自相关性分析，但对这一现象的解读（大户型多在郊区、小户型集中在市中心）是我结合福州城市结构自行推断的。
- **数据局限性分析**：报告中关于样本来源单一（仅安居客）、关键变量缺失（学区、地铁、装修等）的局限性讨论，是我根据数据实际情况和对房地产领域的理解自行总结的。
- **各发现之间的逻辑串联**：报告中五个核心发现之间的逻辑关系和组织顺序，是我在完成全部分析后自行梳理的，确保报告形成完整的分析叙事。
